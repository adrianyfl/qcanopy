Simulator profile

Correctness

Each pair runs on |0…0⟩ plus random product-state probes. Correct: the overlap ⟨Aψ|Bψ⟩ agrees with the generator's proven label and, at small sizes, both states match an independent reference simulation amplitude for amplitude. Incorrect means an equivalent pair produced different states, a state left the unit sphere, or the simulator disagreed with the reference — a simulator, DAG or normalization bug. Undetected: a non-equivalent pair whose probe states all matched (a probe limitation, rare with ≥ 2 probes).
